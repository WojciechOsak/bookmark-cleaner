# Privacy Policy

Bookmark Cleaner reads Chrome bookmarks only to display them and let you move or delete them. It stores the most recently deleted batch locally in `chrome.storage.local` so you can restore it.

The extension does not send bookmarks or other user data to a server, collect analytics, or show ads. The Buy Me a Coffee link opens an external website only when you click it.

Data obtained from Chrome APIs is used in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.
