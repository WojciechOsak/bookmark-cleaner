# Prywatność / Privacy

Bookmark Cleaner odczytuje zakładki Chrome wyłącznie po to, aby wyświetlać je i pozwalać użytkownikowi na ich przenoszenie oraz usuwanie. Ostatnią usuniętą partię zapisuje lokalnie w `chrome.storage.local`, aby umożliwić cofnięcie operacji.

Rozszerzenie nie wysyła zakładek ani danych użytkownika na serwer. Nie zbiera danych analitycznych i nie korzysta z reklam. Łącze Buy Me a Coffee otwiera zewnętrzną stronę wyłącznie po kliknięciu użytkownika. Dane uzyskane z API Chrome są używane zgodnie z zasadą Limited Use w Chrome Web Store User Data Policy.

---

Bookmark Cleaner reads Chrome bookmarks only to display them and let the user move or delete them. The most recently deleted batch is stored locally in `chrome.storage.local` so it can be restored.

The extension does not send bookmarks or user data to a server, collect analytics, or show ads. The Buy Me a Coffee link opens an external page only when the user clicks it. Data obtained from Chrome APIs is used in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.
